# Handoff: IT TIME NOW — Дизайн-система

## Overview
Дизайн-система digital-студии **IT TIME NOW**. Описывает фирменный язык: основной горизонтальный логотип студии, сокращенный знак для аватарок и фавикона, цветовые токены, типографику, рукописную (карандашную) графику и базовые UI-компоненты (кнопки, поля ввода, карточки, состояния). Назначение — единый источник правды для лендингов, кабинетов и внутренних сервисов студии.

Ключевая идея бренда: **«Делаем сложное ИТ — простым, а скучное — крутым!»** Чистый гротеск держит смысл и порядок, синий рукописный слой (маркер #232BFF) добавляет «человеческий» характер.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототип, фиксирующий внешний вид и поведение, а **не продакшн-код для прямого копирования**.

Задача — **воссоздать эти дизайны в целевой кодовой базе** её собственными средствами и паттернами (React, Vue, Svelte, SwiftUI, нативный код и т.д.). Если окружения ещё нет — выбрать подходящий фреймворк и реализовать там. Токены ниже стоит занести в существующую систему тем (CSS-переменные / theme-провайдер / design tokens), а не хардкодить по месту.

`IT TIME NOW — Design System.dc.html` — это «Design Component»: HTML-шаблон + класс логики. Воспринимайте его как живую документацию; копировать его рантайм (`support.js`, `<x-dc>`) в продакшн не нужно — берите из него разметку, стили и значения.

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы и состояния. Воспроизводить UI пиксель-в-пиксель средствами кодовой базы. Все значения — точные (см. Design Tokens).

## Interactions & Behavior

### Кнопки
- **Base**: pill, min-height 44px, padding `0 30px`, Onest 700 14px, animated fill-circle and arrow.
- **Primary / Consultation**: фон `#232BFF`, текст белый, hover — белая поверхность, синий текст, border `#DFE4F2`.
- **Secondary**: текст `#232BFF`, фон `rgba(255,255,255,.76)`, border `#DFE4F2`, hover — синий фон, белый текст.
- **Dark**: фон `#111111`, hover — `#232BFF`.
- **Ghost**: muted-текст, transparent, hover — белая поверхность.
- **Icon buttons**: 44×44 pill, hover clone-анимация иконки справа налево.

### Поля ввода
- **Default**: border `1.5px solid #DFE4F2`, radius 12px, padding `14px 16px`, текст 16px `#111`, фон `#fff`, `outline:none`.
- **Focus**: border `1.5px solid #232BFF` + focus-ring `box-shadow: 0 0 0 4px rgba(35,43,255,0.12)`.
- **Error**: border `1.5px solid #FF5C39` + ring `0 0 0 4px rgba(255,92,57,0.12)`; лейбл и текст ошибки `#FF5C39`; иконка «!» — белая в круге 16px `#FF5C39`. Текст: «Похоже, не хватает цифр».
- **Success**: фон `#F5F7FF`, border `1.5px #DFE4F2`, рядом рукописная галочка `decorations-split/deco-check-03.png` (height 22px). Текст: «Принято».

### Прочее
- Лейблы/токены/eyebrow-надзаголовки — всегда JetBrains Mono, uppercase, letter-spacing ~0.08–0.14em.
- Рукописные ассеты вставляются как `<img>` (PNG с прозрачностью); на цветном фоне инвертируются `filter:brightness(0) invert(1)`.
- Responsive: все сетки на `auto-fit/minmax` + `flex-wrap`, схлопываются в один столбец на узких экранах. Контентная колонка фиксирована 1180px max + боковые паддинги 48px.
- `::selection` — фон `#232BFF`, текст белый.

## State Management
Минимум состояния (демо-уровень; в проде по необходимости):
- **Тема баннера с маскотом** — boolean `mascotDark` (по умолчанию `true`). `true` → синяя тема, `false` → светлая. В прототипе это tweak-проп; в проде — обычный пропс/вариант компонента.

### Типографика
- **Onest** (Google Fonts), веса 300/400/500/600/700/800 — заголовки, UI, текст. Поддержка кириллицы.
- **JetBrains Mono** (Google Fonts), веса 400/500/700 — метки, токены, eyebrow, код.
- Основная шкала: H1 `clamp(42→72)` / 800; H2 `clamp(34→52)` / 700; H3 26 / 700; H4 22 / 700; H5 18 / 700; H6 16 / 700 uppercase; Body 18 / 400; UL/OL 18 / 400; Caption/mono 12–14 / 400–500.
- Letter-spacing: крупные заголовки −0.02…−0.03em; mono-метки +0.06…+0.14em uppercase.
- Line-height: заголовки 0.92–1.05; текст 1.4–1.5.

### Радиусы
- Кнопки/инпуты: 12px · карточки малые: 14–16px · карточки крупные: 18–20px · баннер: 24px · таблетки/пилюли: 999px.

### Тени
- Hover primary-кнопки: `0 8px 24px rgba(17,24,207,0.28)`.
- Focus-ring: `0 0 0 4px rgba(35,43,255,0.12)`; error-ring: `0 0 0 4px rgba(255,92,57,0.12)`.

### Spacing
- Секционные паддинги: `88px 48px` (по вертикали 88, по бокам 48). Шапка `80px 48px 56px`, футер `64px 48px 88px`.
- Сеточные gap: 16–28px. Контент max-width 1180px.
