# Исправления по SEO ТЗ IT TIME NOW

Дата: 15 ноября 2026 года. Основание: SEO developer ТЗ версии 1.27.1, снимок от 10 ноября. Проверены все 40 URL из исходного файла на локальной production-сборке с доменом https://ittimenow.com. Изменения не опубликованы на сервере.

## Что осталось в выдаче валидатора

Nu Html Checker версии 26.11.14 проверил все 40 файлов локально. Внешняя проверка начала возвращать HTTP 429, поэтому итоговые результаты получены автономным официальным валидатором; зависимости проекта не устанавливались.

- Ошибки HTML: **0**.
- Предупреждения: **0**.
- CSS-сообщения о View Transitions: **463**, включая 295 Parse Error, 116 сообщений о plus-lighter и 52 о view-transition-name.
- Информационные сообщения о завершающем слеше пустых тегов: **163**. Атрибуты заключены в кавычки, слеш не влияет на разбор.

Все 295 контекстов CSS Parse Error относятся к селекторам View Transitions. Свойство view-transition-name, соответствующие псевдоэлементы и plus-lighter описаны в [спецификации CSS View Transitions Level 1](https://www.w3.org/TR/css-view-transitions-1/). Эти сообщения классифицированы как ограничения CSS-проверки валидатора; анимации сохранены. Итог нельзя описывать как отсутствие вообще всех сообщений W3C.

Подробные результаты с URL и исходными сообщениями: [validation.json](./validation.json).

## Проверки проекта и браузера

- Astro check: 116 файлов, без ошибок, предупреждений и подсказок.
- Автоматические тесты: 53 из 53 прошли.
- Production-сборка завершилась успешно. Сохраняется прежнее предупреждение Vite о размере JS-чанка более 500 КБ; оптимизация чанков не входила в это ТЗ.
- Проверка сборки: 47 HTML-файлов, включая служебные страницы и редиректы, 4332 локальные ссылки и ресурса. Битых ссылок и ресурсов не найдено.
- В проверку сборки добавлен контроль содержимого после закрывающего html, источников изображений, связи sizes/srcset, NFC для alt, подписей generic div, заголовков article/section и уровней заголовков команды. Структурные проверки SEO ограничены публичными страницами.
- В браузере проверен переход слайдера El Rey на второй слайд и его aria-current. Для каталога блога на ширинах 390 и 1440 px отсутствует горизонтальное переполнение, меню остаётся fixed, геометрия CTA соответствует ширине экрана. Проверены доступность файла иллюстрации и его декодирование.
